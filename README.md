# Hidden Guest OS

THE GATE Mystery Guest Questionnaire is an Arabic-first, responsive readiness and training system for hotel front-desk teams.

## Features

- Mystery guest exams with weighted scoring and critical failures
- Training cards with standards and best responses
- Phone-call simulator
- Before-shift readiness checklist
- Weak-points tracking with local storage
- Question builder and CSV/PDF-ready reports
- RTL interface for mobile, tablet, and desktop

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
